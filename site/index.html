A free toolkit for knowledge graphs.

Create, store, and explore connected knowledge, on your own machine or across a team. We’re building graph-ted in the open, starting with the piece that’s ready.

Meet graph-ted-db Follow along on GitHub

Why the database first?

While building the full toolkit, we found the database was already useful on its own. graph-ted-db keeps a complete graph in a plain folder, with no server to run, and you can share it through the file-sync service you already use. So we’re releasing it early and letting real use shape what comes next.

It’s early. Expect rough edges and tell us about them.

Principles

  • Local-first

    A graph starts as files on your own machine. There is no server to run for the default path, and your work does not depend on a connection.

  • Your storage and network are the security boundary

    Data is stored as ordinary files. Protect it the way you protect your other files: disk encryption, account permissions, backups, and what you expose on the network.

  • Open and agent-friendly

    Readable on-disk formats, a documented Python API, and docs published as llms.txt so agents can read them too.
