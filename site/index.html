Right-sized graphs that start local, share like files, and go offline.

graph-ted is a family of tools for working with graphs that fit on your machine. Keep a graph in a folder you own, share a graph through your file-sync service, and keep working when you are offline.

See the projects graph-ted on GitHub

Projects

graph-ted-db

Local property-graph storage for Python. Your graph lives in a folder of plain files on disk. Open it in-process, query it with a Cypher subset, and share a graph through your file-sync service.

$ pip install graph-ted-db
from graph_ted_db import GraphStore, init_graph
init_graph("./my-graph", name="demo", exist_ok=True)
g = GraphStore.open("./my-graph")
g.make_node(labels=["Person"], props={"name": "Alice"})

Requires Python 3.10+. Until the package is on PyPI, install from a git checkout: pip install -e .

Principles

  • Local-first

    A graph starts as files on your own machine. There is no server to run for the default path, and your work does not depend on a connection.

  • Your storage and network are the security boundary

    Data is stored as ordinary files. Protect it the way you protect your other files: disk encryption, account permissions, backups, and what you expose on the network.

  • Open and agent-friendly

    Readable on-disk formats, a documented Python API, and docs published as llms.txt so agents can read them too.
